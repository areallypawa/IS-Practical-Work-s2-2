# 📊 Сравнение производительности двусвязного списка и динамического массива

Данная работа посвящена изучению структур данных **двусвязного списка** и **динамического массива**, а также сравнению их производительности при выполнении основных операций.

---

# 🎯 Цели работы

- Изучение свойств и организации двусвязных списков  
- Получение практических навыков работы с динамическими массивами и списками  
- Сравнение производительности операций:
  - вставка элементов
  - доступ к элементам
  - удаление элементов  

---

# ⚙️ Функциональность программы

Программа поддерживает работу с двумя структурами данных:

- 📌 двусвязный список  
- 📌 динамический массив  

Реализация выполнена параллельно для обеих структур.

---

# 1️⃣ Формирование структуры данных

Пользователь может создать структуру двумя способами:

### 🔹 Автоматическое заполнение
- Вводится количество элементов `N`
- Структура заполняется случайными числами (0–99)

### 🔹 Ручное заполнение
- Пользователь вводит элементы вручную
- Размер определяется автоматически

---

# 2️⃣ Измерение времени создания

Программа измеряет время:
- создания списка
- создания массива

Результат выводится в консоль для сравнения.

---

# 3️⃣ Базовые операции

Поддерживаются следующие операции:

### ➕ Вставка
- вставка элемента по индексу

### ❌ Удаление
- удаление по индексу  
- удаление по значению (первое совпадение)

### 🔍 Получение
- доступ к элементу по индексу  

### 🔄 Обмен
- swap двух элементов по индексам  

---

# 4️⃣ Измерение производительности

Для каждой операции измеряется время выполнения:
- вставка
- удаление
- доступ

Результаты выводятся для обеих структур данных.

---

# ⚠️ Особенности реализации

- Возможность многократного выполнения операций  
- Проверка на пустую структуру данных  
- Защита от некорректных операций  
- Сравнение результатов между структурами  

---

# 🚀 Использование программы

1. Запустить программу  
2. Выбрать структуру:
   - двусвязный список  
   - динамический массив  
3. Создать структуру:
   - автоматически  
   - вручную  
4. Выполнять операции и наблюдать время  
5. Повторить для второй структуры  
6. Сравнить результаты
